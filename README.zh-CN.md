# FocusClaim

[English](README.md) | 简体中文

FocusClaim 是一个轻量的 WoW 正式服插件，用于将鼠标指向单位设置为焦点、添加团队标记并向队伍宣布焦点。

## 功能

- 使用 `Shift / Alt / Ctrl + 左键` 将任意鼠标指向单位设置为焦点
- 在空白处使用相同快捷键移除当前焦点标记并清除焦点
- 将所选团队标记移动到新焦点
- 向队伍、副本或团队频道发送 `我焦点打断 {rtN} {怪物名称}`
- 可以关闭喊话，同时保留焦点和标记行为
- 支持暴雪原生单位框和姓名板、DandersFrames、EllesmereUI、Enhance QoL 和 UUF 的单位框、队伍框与团队框
- 可选的可移动焦点施法条，显示打断就绪时间线

FocusClaim 会优先占用所选修饰键与左键组合。支持的单位框上如果已有相同组合的点击施法，该绑定会被覆盖。

## 使用

输入 `/fc` 或 `/focusclaim` 打开设置页。设置包括：

- 团队标记 `1-8`
- 修饰键 `Shift / Alt / Ctrl`
- 喊话频道 `关闭 / 队伍 / 副本 / 团队`
- 可选的焦点施法条（默认锁定）；解锁后可拖动并保存位置
- 可编辑的灰色、绿色、橙色和中性色

施法条默认关闭，通常仅在焦点正在施法或引导时显示；启用并解锁后，无施法时也会显示位置预览以便拖动。施法期间会展示法术图标、名称和剩余时间。颜色表示不可打断、打断就绪或暂不可打断；若打断在施法过程中冷却结束，时间线上会标出该边界。未知或超出距离的状态不会错误显示为可打断。打断检测会跟随已学会的职业、专精或宠物打断技能。

新角色默认使用 `Shift + 左键`、骷髅标记和队伍频道。配置按角色保存在 `FocusClaimSettings` 中。

## 设计

FocusClaim 将一条短宏直接写入安全按钮和支持的单位框，不再创建或管理角色宏。

多个刷新请求会自动合并，重复发现的框架会去重，安全属性只在绑定计划变化时重写。设置控件仅在首次打开设置页时创建。独立焦点施法条使用原生施法/冷却持续时间对象以及安全的颜色和透明度操作处理施法计时与可打断状态。

简体中文默认宏为：

```text
/tm [@focus]0
/clearfocus [@mouseover,noexists]
/stopmacro [@mouseover,noexists]
/focus [@mouseover,exists]
/tm [@mouseover]8
/p 我焦点打断 {rt8} %f
```

战斗中修改的设置会在脱战后生效。
